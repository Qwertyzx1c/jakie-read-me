# jakie-read-me



- Utwórz klase 'mysqldb' która dziedziczy po klasie abstrakcyjnej 'database' właściwości, metody oraz metody abstrakcyjne.
- Dołącz do klasy 'mysqldb' interfaceDołącz interface 'sqlinterface' do msqldb.
- Abstrakcyjna klasa powinna zawierać odpowiednie właściwości do połączenia się z bazą danych za pomocą funkcji 'mysqliconnect'.
- Abstrakcyjna klasa 'database' ma zawierać odpowiednie metody do operowania na 'CRUT'.

1. Tworzenie bazy danych
2. Tworzenie tabeli
3. Odczytywanie z tabeli danych
4. Aktualizacja tabeli
5. Usuwanie tabeli



Sqlinterface ma implementować metody takie jak: 
- Find All()
- Find()
- Read One
- Read First Ten()



 - Wszystkie metody obiektu z klasy 'mysqldb' mają być sprawdzone i wywołane w kodzie.
